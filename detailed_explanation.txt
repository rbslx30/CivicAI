=========================================
   CIVIC AI - DETAILED A-Z EXPLANATION
=========================================

1. WHAT IS CIVIC AI? (The Core Concept)
CivicAI is an automated, AI-powered public grievance redressal system. In simpler terms, it's a platform where citizens can report civic issues (like potholes, water leaks, or safety hazards).

The Problem it Solves: Traditional government portals are often English-only, confusing to navigate, and slow. Complaints get routed to the wrong departments, and citizens never know the status of their issues.

The Solution: CivicAI allows users to speak or type in their native language. The AI translates it, figures out what the problem is, assigns a priority level, and routes it directly to the correct government department.

-----------------------------------------
2. THE CITIZEN JOURNEY (Frontend & UI)
The citizen-facing side is built with blazing-fast Vanilla JavaScript, HTML, and CSS (Zero bloated frameworks) to ensure it works smoothly on low-end mobile devices common in rural areas.

* Filing a Grievance (index.html & script.js):
  - Multilingual Input: Users can select from 20+ regional Indian languages. A custom Google Translate integration translates the UI on the fly.
  - Input Methods: Users can type their complaint or use the Mic Button to record an audio snippet (Voice-to-Text).
  - CivicAI Copilot: A chat-based assistant overlay that guides users step-by-step (Category -> Location -> Issue -> Details) if they don't want to fill out a traditional form.
  - Cinematic UI: The app features a simulated "Boot Sequence" and animated counters to make the platform feel robust and modern.

* Tracking a Grievance (track.html & track.js):
  - Once submitted, the citizen gets a unique Tracking ID (e.g., APP20260506123456).
  - By entering this ID or their phone number, they can see a real-time, interactive timeline of their grievance journey (e.g., "Submitted" -> "Under Review" -> "Field Officer Assigned" -> "Resolved").

-----------------------------------------
3. THE "BRAIN" (AI & NLP Pipeline)
When a user hits "Submit", the data doesn't just go to a database; it passes through a multi-step AI pipeline before an admin ever sees it.

* Language Detection (languageDetector.js): Uses Unicode block Regex to instantly figure out if the user typed in Hindi, Bengali, Tamil, etc., without requiring them to explicitly state it.
* Translation (translator.js): Normalizes the regional text into English so government officials have a standardized record.
* Text Preprocessing (nlpPreprocessor.js): Cleans the text by converting it to lowercase, stripping punctuation, and removing "stop-words" (like 'is', 'the', 'hai', 'aur').
* Priority Detection (priorityDetector.js): Scans the text for severe keywords. Words like "fire," "accident," "blood," or "murder" instantly flag the complaint as Urgent. Words like "bribe" or "assault" flag it as High priority.
* Smart Routing: Based on the text, the system deterministically assigns the complaint to the right bucket (e.g., "Public Works Department" for roads, "Health & Family Welfare" for sanitation).

-----------------------------------------
4. THE BACKEND & DATABASE (Node.js & MongoDB)
The backend acts as the secure bridge between the AI, the citizen, and the database.

* Database (MongoDB Atlas): Stores everything in a highly scalable NoSQL format. The `Complaint` collection holds the citizen's details, original text, translated text, AI's confidence score, and an array of timelineLogs.
* API Endpoints (dashboardController.js & Routes):
  - POST /api/complaints: Receives the raw data, triggers the AI pipeline, saves to the DB, and returns the Ticket ID.
  - GET /api/complaints/track: Queries the database for a specific ticket to populate the tracking timeline.

-----------------------------------------
5. THE GOVERNMENT DASHBOARD (Admin Portal)
The government side is designed for efficiency, allowing officers to triage complaints rapidly.

* Overview (dashboard.html & dashboard.js):
  - A secure, JWT-authenticated portal.
  - Live Metrics: Shows total complaints, pending vs. resolved, and high-priority alerts.
  - AI Insights Panel: Displays generative insights (e.g., "Water complaints likely to rise 15% next week due to seasonal patterns").

* Grievance Management:
  - Officers can view the original text alongside the AI-translated text.
  - They see the AI Explainability (why the AI routed it to them and why it gave it a specific priority).
  - Lifecycle Actions: With one click, an officer can Accept, Reject, Mark "In Progress," or Resolve a complaint. Doing so automatically pushes a timestamped update to the citizen's tracking page.
  - Internal Notes: Officers can leave private remarks that citizens cannot see.
  - Exporting: Data can be exported to CSV for government audits.

-----------------------------------------
6. SECURITY & SCALABILITY
* Stateless Auth: Uses JSON Web Tokens (JWT) for the admin dashboard.
* Demo/Hackathon Readiness: The codebase includes a generateDemoData.js script to instantly populate the dashboard for presentations, and a "Demo Mode" toggle right in the UI.
* Resilience: The frontend utilizes sessionStorage to maintain state smoothly between page transitions, ensuring the user doesn't lose their Ticket ID right after submission.

-----------------------------------------
SUMMARY
CivicAI takes a messy, bureaucratic, paper-heavy process and digitizes it. By putting an NLP layer in the middle, it ensures that a citizen speaking Marathi in a rural village can report a broken pipe, and the Water Department receives a perfectly categorized, translated, high-priority English ticket seconds later.
